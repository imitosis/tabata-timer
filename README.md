# Tabata Timer

Ein einfacher, klassischer Tabata-Timer im Browser – ohne Installation, ohne Anmeldung.

## Funktionen
- Phasen: Vorbereitung, Belastung, Pause, Satzpause
- Große Zeitanzeige, eigene Farbe pro Phase
  - Gelb = Vorbereitung · Rot = Belastung · Grün = Pause · Blau = Satzpause · Lila = Fertig
- Töne: Countdown-Piepser (3-2-1), Startsignal, Pausensignal, Abschlussmelodie
- Vibration auf dem Handy (wo unterstützt)
- Bildschirm bleibt während des Trainings an
- Einstellungen werden im Browser gespeichert
- Standard: 10 s Vorbereitung, 8 × (20 s Belastung / 10 s Pause)

## Benutzen
Einfach `index.html` im Browser öffnen – oder über GitHub Pages aufrufen.

Tastatur: **Leertaste** = Pause/Weiter, **Esc** = Stopp, **Enter** = Start.
